# Hashmap Playground

A simple command-line tool demonstrating basic hashmap operations in Rust.

## Usage

Run the program with `cargo run`.

The program will:

1.  Create a new hashmap.
2.  Insert some key-value pairs.
3.  Retrieve values by key.
4.  Demonstrate updating a value.
5.  Show how to remove a key-value pair.
6.  Iterate over the hashmap.
