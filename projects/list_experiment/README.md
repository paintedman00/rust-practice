# Linked List Experiment

A simple command-line tool for experimenting with linked lists in Rust.

## Usage

Run the program with `cargo run`.

## Functionality

This program provides a basic demonstration of creating, manipulating, and traversing a singly linked list.  It allows you to add elements, remove elements, and print the contents of the list.

## Building

```bash
cargo build
```

## Running

```bash
cargo run
```
