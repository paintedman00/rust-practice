# Hash Map Demo CLI

A simple command-line tool demonstrating the usage of hash maps in Rust.

## Usage

Run the program with `cargo run`.

The program will:

1.  Create a hash map.
2.  Insert some key-value pairs.
3.  Retrieve values by key.
4.  Demonstrate handling of missing keys.

## Building

```bash
cargo build
```

## Running

```bash
cargo run
```
