# cli_arg_parser

A simple command-line argument parser example in Rust.

## Usage

```bash
cargo run -- [options]
```

Options:

*   `--name <name>`: Specifies a name.
*   `--age <age>`: Specifies an age (integer).
*   `--verbose`: Enables verbose output.
*   `--help`: Shows this help message.

## Example

```bash
cargo run -- --name John --age 30 --verbose
```
