# Hex Peek

A simple command-line utility to display the hexadecimal representation of a file's contents.

## Usage

```bash
hex_peek <file_path>
```

Replace `<file_path>` with the path to the file you want to inspect.

## Example

```bash
hex_peek my_file.txt
```

This will print the hexadecimal representation of `my_file.txt` to the console.
