# File Size Histogram

This command-line tool analyzes files in a directory and generates a histogram of their sizes.

## Usage

```bash
file_size_histogram <directory>
```

Replace `<directory>` with the path to the directory you want to analyze.  If no directory is provided, the current directory is used.

## Example

```bash
file_size_histogram /path/to/your/directory
```

## Output

The program outputs a histogram showing the distribution of file sizes.  The file sizes are grouped into buckets, and the number of files in each bucket is displayed.
